# Cifra de César

## Projeto de implementação da Cifra de César

Este projeto implementa o algoritmo de criptografia da Cifra de César.
<br>
### Faça o clone do projeto:
```bash
git clone https://github.com/VictorLemos1000/CifraDeCesar.git
```
### Verifique a sua versão python:
```bash
python3 --version
```
### Intalação do python 3:
```bash
sudo apt install python3 python3-pip
```
### Como rodar o projeto no via terminal: 
```bash
python3 -m http.server 8000
```
